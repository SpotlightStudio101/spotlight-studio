## Scope

Route: `/films`. Mode: Experience — the work leads; the interface recedes.

## Audience, job, action, proof, constraints

Audience: potential clients scanning range and craft before deciding to book a call. Job: see the breadth of work fast, then click into a piece that convinces them. Action: click a tile, or leave convinced enough to book from Home. Proof: the clips themselves, already playing. Constraints: no real films exist yet — ships with a fixed set of clearly-labeled placeholder tiles (distinct placeholder color/pattern per tile, no stock footage passed off as real work) sized for a future swap to real clips.

## Direction contract

THESIS: The grid plays itself before you touch anything — refuses the portfolio-grid default of static thumbnails that only animate on hover.

OWN-WORLD: Inherits Home's screening-room world (near-black ground, projector-amber accent used only for interactive state, condensed/grotesk type, zero card chrome). Edge-to-edge 3-column grid, near-zero gutter, full-bleed tiles exactly as in the pinned reference (dannygevirtz.com/dannysprojects). No title text rendered on the grid itself — titles exist as accessible link text only, consistent with the pinned reference.

STORY: Visitor understands the range (commercial, documentary, narrative) at a glance because every tile is already moving. Visitor believes the craft is real because nothing is staged as a static "portfolio photo." Visitor clicks toward whichever genre matches their need, or returns to Home to book.

FIRST VIEWPORT: Minimal transparent top bar (name wordmark left, MENU control right) over a 3-column, edge-to-edge grid of tiles beginning immediately below it, each tile autoplaying a muted looping placeholder clip (or a clearly labeled "coming soon" motion placeholder where no clip exists) the moment the page loads — no click or hover required. Grid continues below the fold at the same density; no additional hero section above it.

FORM: Same screening-room world as Home (see `.impeccable/surfaces/home.md`) — brief-pinned to dannygevirtz.com/dannysprojects specifically for this surface's structure. No separate concept-seed roll for this surface: it extends Home's already-settled world per an established-world surface, resolving only this surface's composition.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
